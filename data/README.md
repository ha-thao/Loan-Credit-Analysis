# Data

This project uses the **Realistic Loan Approval Dataset (US & Canada)** from Kaggle.

**Source:** https://www.kaggle.com/datasets/parthpatel2130/realistic-loan-approval-dataset-us-and-canada

The dataset contains approximately **50,000 loan applications** and **20 financial and credit-related variables**, including credit score, debt-to-income ratio (DTI), loan amount, income, employment history, and loan approval status.

The original dataset is publicly available on Kaggle. Please download it directly from the source link above.
